# Mission: Rust for CLI tools, backend services and Flutter

## Why
I build Flutter apps in Dart and want Rust for three jobs: command-line tools, backend services, and native code inside Flutter apps via `flutter_rust_bridge`.

## Success looks like
- A small CLI tool of my own (`clap`, `serde`), cleanly split into modules
- An HTTP API with `axum`, `sqlx` and `tracing`
- Rust code called from a Flutter app on Android and iOS

## Constraints
- Coming from Dart (since 2014), some Go and a little Rust: compare with Dart, skip programming basics
- One topic per session: theory first, then exercises in `src/main.rs` checked by `cargo test`
- Chat explanations in German, everything in the repository in English

## Out of scope
- Embedded, game development, WebAssembly front ends
