Structs & impl

Cheat sheet. Source: Rust Book ch. 5, API Guidelines.

Skeleton

struct Task {                 // data only; own your data (String, not &str)
    title: String,
    done: bool,
}

impl Task {
    fn new(title: &str) -> Self {                  // associated fn, called Task::new(..)
        Self { title: title.to_string(), done: false }
    }
    fn is_done(&self) -> bool { self.done }        // read
    fn complete(&mut self) { self.done = true; }    // change
    fn into_title(self) -> String { self.title }    // consume
}

Constructor conventions

new(..)main constructor (just a convention, not a keyword)
with_…(..)variant with extra settings: Vec::with_capacity(n)
from_…(..)conversion from another value
Defaulttrait for the obvious empty value (session 9)
No overloading: different parameters → different name.

Literal syntax

Task { title, done: false }      // field init shorthand (variable `title`)
Task { done: true, ..other }     // struct update: rest from `other`, MOVES non-Copy fields; `..` last
struct TaskId(u32);  id.0         // tuple struct / newtype
struct Marker;                   // unit-like struct
