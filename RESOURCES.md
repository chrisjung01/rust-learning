# Rust Resources

## Knowledge

- [Book: _The Rust Programming Language_ (the Rust Book)](https://doc.rust-lang.org/book/)
  The official book, the backbone of Phase 1. Use for: every language topic, one chapter per session.
- [Rust Book, ch. 5: Using Structs](https://doc.rust-lang.org/book/ch05-00-structs.html)
  Defining structs, `impl`, methods, associated functions. Use for: session 2.
- [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/)
  How idiomatic library APIs are named and shaped (constructors, conversions, getters). Use for: "what is the idiomatic way to write this signature?"
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/)
  Short runnable snippets per feature. Use for: a second angle when a Book chapter feels abstract.
- [Dart language tour: Constructors](https://dart.dev/language/constructors)
  Reference for the Dart side of comparisons (named, factory, const constructors).

## Wisdom (Communities)

- [Rust Users Forum](https://users.rust-lang.org/)
  Official, well-moderated forum for questions of any level. Use for: "is this idiomatic?", code reviews of the CLI project.
- [r/rust](https://www.reddit.com/r/rust/)
  Large community, news and discussion. Use for: ecosystem questions (which crate?), following Rust releases.
